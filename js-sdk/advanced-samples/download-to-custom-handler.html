Download to custom handler

Open the manager, trigger a file download from the embedded UI, and inspect the intercepted download URL. With downloadToEvent: true, the SDK sends the payload to onDownload instead of starting the browser download automatically.

Use this when your application needs to control the download flow itself: for example, to log downloads, show a custom confirmation step, or forward the URL to your own backend.

Ready

How to test it: after the manager loads, open a file menu or toolbar action in DocSpace and click Download. The URL will appear here instead of downloading immediately.
